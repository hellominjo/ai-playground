# AI 도구

대화형 서비스부터 에이전트와 언어 모델까지, 필요한 주제부터 살펴보세요.

- Conversational AI

  **[ChatGPT](/ai-tools/chatgpt)**

  질문, 글쓰기, 자료 정리 등 일상 업무에 활용하는 방법과 프롬프트를 기록합니다.

  시작하기 · 업무 활용 · 프롬프트

- Conversational AI

  **[Claude](/ai-tools/claude)**

  문서 읽기와 작성, 코드 작업에 활용하며 얻은 경험과 실습을 정리합니다.

  시작하기 · 문서 작업 · 코딩

- Agent & Workflow

  **[AI Agent](/ai-tools/ai-agent)**

  도구를 연결하고 여러 단계의 작업을 수행하는 에이전트의 개념과 활용을 실험합니다.

  기본 개념 · 도구 연결 · 워크플로

- Models & Concepts

  **[LLM](/ai-tools/llm)**

  언어 모델의 기본 개념, 모델 선택 기준, 프롬프트와 컨텍스트를 이해합니다.

  모델 이해 · 모델 선택 · 컨텍스트
