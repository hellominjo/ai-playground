# AI Playground

**AI Playground**는 AI 도구와 일하는 방식을 직접 실험하고, 그 과정에서 배운 내용을 기록하는 공간입니다. 

AI 도구를 배우고, 직접 만들고, 업무에 연결해 본 방법들을 공유합니다. <br />
작은 아이디어를 결과물로 만들고, 실행하며 얻은 인사이트와 시행착오를 쌓아 놓고 있습니다.

## 작은 실험에서 시작합니다

### 도구 살펴보기

어떤 일을 할 수 있는지, 내 작업의 어디에 사용할 수 있는지
살펴봅니다. 기능을 모두 익히기보다 지금 필요한 것부터 시작합니다.

### 직접 만들어 보기

작은 화면이나 하나의 기능을 만들어 봅니다.
목표와 필요한 기능, 원하는 결과를 구체적으로 전달합니다.

### 결과를 보고 개선하기

만들어진 결과를 직접 사용해 보고,
기대한 동작과 다른 부분을 찾아 다시 요청합니다.

### 실행하고 검증하기

AI의 완료 응답에서 멈추지 않고 실제 결과를 확인합니다.
웹사이트를 만들었다면 다음 항목부터 살펴보세요.

확인한 결과와 남은 문제를 기록하고 다음 시도에 반영합니다.

## Lab Notes

정답을 찾기보다, 시도한 과정을 남기는 공간입니다.

- 01 / Discovery

  **작게 요청할수록 명확하게**

  한 번에 전체 앱을 만들기보다, 하나의 기능씩 확인하며 진행합니다.
  작업의 범위를 줄이면 결과를 판단하기 쉽고 문제가 생긴 지점도 더 명확해집니다.

- 02 / Iteration

  **결과를 보고 다시 질문하기**

  오류 메시지와 기대한 동작을 함께 전달하면 개선 방향이 구체적이 됩니다.
  무엇을 했고 어떤 결과가 나왔는지 설명합니다.

- 03 / Reflection

  **다음에도 쓸 수 있게 기록하기**

  사용한 도구와 설정, 시도한 방법, 확인한 결과와 남은 질문을 함께 남깁니다.
  작은 기록이 다음 실험의 출발점이 됩니다.

- 04 / Sharing

  **배운 것을 나누며 다듬기**

  정리한 기록을 공유하고 다른 사람의 피드백을 받습니다.
  설명하는 과정에서 놓친 부분을 발견하고, 이해가 한층 깊어집니다.


## AI Tool

대화형 서비스부터 에이전트와 언어 모델까지, 필요한 주제부터 살펴보세요.

- Conversational AI

  **[ChatGPT](/ai-tools/chatgpt)**

  질문, 글쓰기, 자료 정리 등 일상 업무에 활용하는 방법과 프롬프트를 기록합니다.

  시작하기 · 업무 활용 · 프롬프트

- Conversational AI

  **[Claude](/ai-tools/claude)**

  문서 읽기와 작성, 코드 작업에 활용하며 얻은 경험과 실습을 정리합니다.

  시작하기 · 문서 작업 · 코딩

- Agent & Workflow

  **[AI Agent](/ai-tools/ai-agent)**

  도구를 연결하고 여러 단계의 작업을 수행하는 에이전트의 개념과 활용을 실험합니다.

  기본 개념 · 도구 연결 · 워크플로

- Models & Concepts

  **[LLM](/ai-tools/llm)**

  언어 모델의 기본 개념, 모델 선택 기준, 프롬프트와 컨텍스트를 이해합니다.

  모델 이해 · 모델 선택 · 컨텍스트
